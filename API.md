# API Documentation

Full interactive docs (auto-generated by FastAPI from the Pydantic schemas)
are available at `/docs` (Swagger UI) and `/redoc` once the backend is
running. This file is a quick-reference summary.

Base URL: `http://localhost:8000/api`

## Auth
| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/auth/google/login` | none | Exchanges a Google ID token for our session JWT. Creates the user on first login. |
| GET | `/auth/me` | Bearer | Returns the current authenticated user. |
| POST | `/auth/logout` | none | Stateless — client discards the token. |

## Products
| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/products` | none | List all products (public catalog). |
| GET | `/products/{id}` | none | Get one product. |
| POST | `/products` | Admin | Create a product. |
| PATCH | `/products/{id}` | Admin | Update a product. |
| DELETE | `/products/{id}` | Admin | Delete a product. |

## Orders
| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/orders` | Bearer | Create a pending order from cart items. Validates & decrements stock, snapshots prices. |
| GET | `/orders/me` | Bearer | List the current user's own orders. |
| GET | `/orders` | Admin | List all orders (any customer). |
| GET | `/orders/{id}` | Bearer | Get one order — only the owner or an admin may view it. |

## AI Agent
| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/agent/ask` | Bearer | Ask a free-text question; the agent uses tools to answer from real product/order data. |

## Auth header format
```
Authorization: Bearer <jwt>
```

## Error format
```json
{ "detail": "Human-readable error message" }
```
Standard HTTP status codes are used throughout (401 unauthenticated, 403
forbidden/wrong role or owner, 404 not found, 409 conflict e.g. insufficient
stock, 400 invalid input).
